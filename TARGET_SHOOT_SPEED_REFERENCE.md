# Target Shoot - Speed Control Quick Reference

## Speed Settings

| Setting | Emoji | Multiplier | Best For |
|---------|-------|------------|----------|
| Very Slow | 🐌 | 0.4x | Ages 4-5, learning mode |
| Slow | 🚶 | 0.7x | Ages 6-7, building confidence |
| Normal | 🏃 | 1.0x | Ages 8+, balanced gameplay |
| Fast | 🚀 | 1.4x | Advanced players, more challenge |
| Very Fast | ⚡ | 2.0x | Expert mode, reflex testing |

## How Speed Works

**Final Speed = Level Speed × User Speed**

Example combinations:
- Level 1 (slow) × Very Slow (0.4x) = 0.4x total → Perfect for beginners
- Level 5 (medium) × Normal (1.0x) = 1.5x total → Good balance
- Level 10 (fast) × Very Fast (2.0x) = 4.4x total → Extreme challenge!

## Finding Your Perfect Speed

### For Learning (Focus on Math)
→ Use **Very Slow** or **Slow**
→ Set lower level (1-3)
→ Use Practice Mode

### For Balanced Play
→ Use **Normal** speed
→ Set appropriate level (4-6)
→ Try both modes

### For Challenge
→ Use **Fast** or **Very Fast**
→ Set higher level (7-10)
→ Use Time Attack Mode

## Tips

1. **Start Slow**: Begin with Very Slow to learn the game
2. **Increase Gradually**: Move up one speed level at a time
3. **Match Your Skill**: Speed should complement your math level
4. **Practice First**: Master accuracy before increasing speed
5. **Have Fun**: Choose what feels enjoyable!

## Accessibility

The speed control is perfect for:
- Young children (Very Slow)
- Visual tracking challenges (Slow)
- Motor skill accommodations (Slow/Very Slow)
- Learning disabilities (adjustable pace)
- High-skill players (Fast/Very Fast)

## Keyboard Shortcuts

While in settings:
- Tab: Navigate between options
- Enter/Space: Select option
- Escape: Close settings
